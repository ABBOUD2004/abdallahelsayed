Halla - Salon & Barbershop Booking Platform

Halla - Salon & Barbershop Booking Platform

Halla (هلا) is a complete online booking and management solution tailored for salons and barbershops in Egypt. The platform serves two main user bases:

  1. Customers: Can discover nearby salons, view services, prices, and staff availability, and book appointments seamlessly online.
  2. Business Owners: Empowered with a comprehensive dashboard to manage their calendar, staff shifts, service menus, and client records, alongside booking and revenue analytics.

Key Features & Technical Highlights: • Multi-tenant architecture serving multiple salons independently. • Advanced AI Chatbot Assistant: Integrated Groq API (LLMs) to build a smart assistant that understands Egyptian Arabic, answers user queries, and automatically navigates them to the correct pages. • Smart Location Filtering: Implemented reverse geocoding using OpenStreetMap (Nominatim API) for precise city/governorate filtering. • Seamless UI/UX: Built with Laravel Livewire and Alpine.js for dynamic, single-page-like interactions without page reloads. • Role-Based Access Control (RBAC) handling Admins, Shop Owners, and Customers securely.

Laravel Livewire Tailwind CSS Alpine.js MySQL Groq API AI Chatbot SaaS

Tarek Barber - Salon Management System

Tarek Barber - Salon Management System

Tarek Barber is a full-stack salon management application built to streamline the day-to-day operations of barbershops. It was built to replace a legacy offline database with a robust, cloud-based architecture.

Key Features & Achievements: • Multi-Branch Management: Easily switch between branches and manage specific employees, services, and daily reports per branch. • Smart Booking System: Quick and efficient session recording with live client search, discount management (fixed/percentage/offers), and loyalty points integration. • Employee Management: Track employee attendance, calculate commissions, and manage salaries. • Financial Reporting: Automated daily cash register tracking, expense logging (rent, utilities), and precise revenue calculations. • Performance Optimization: Optimized for mobile (specifically iOS) with lazy loading, deferred Google Fonts, and composite database indexes to handle thousands of records smoothly. • Complex Data Migration: Wrote custom PHP scripts to seamlessly migrate and map thousands of legacy offline SQLite records to the new MySQL architecture without data loss.

Laravel PHP MySQL Alpine.js Tailwind CSS Database Migration SaaS Performance Optimization

The National Foundation

The National Foundation

National Training & Workforce Qualification Platform — Full-Stack Web Application

I’m proud to showcase a complete Full-Stack platform developed for the National Foundation for Training and Workforce Qualification.

The public-facing website features a modern, eye-friendly Dark Theme with a clean and responsive user experience. However, the real challenge—and one of the most significant parts of the project—was the powerful Admin Dashboard built behind the scenes to manage and control the entire platform.

Internal System — Backend & Admin Panel

Course Management System Full control over creating, editing, and managing course details, with real-time monitoring of student bookings and registrations.

Recruitment & Job Management A dedicated dashboard for managing job vacancies, receiving applications, and efficiently reviewing and managing candidates.

Dynamic Content Management System (CMS) Administrators can update website content—including text, images, scholarships, contact information, FAQs, and other sections—without requiring any code changes.

Database Architecture & ERD Designed a structured and interconnected database architecture with complex relationships between entities to ensure efficient data retrieval, scalability, data integrity, and precise user permission management.

🛠️ Technology Stack

Backend: Laravel 11 · PHP 8.3 Database: MySQL · Professional Database Architecture Frontend: HTML5 · CSS3 · Blade · JavaScript Server & Deployment: Ubuntu VPS · Nginx · aaPanel Deployment: Full server configuration, domain integration, security setup, and production deployment

Building this system from the ground up, configuring a real production server, connecting the domain, and securing and deploying the platform was a challenging but extremely valuable experience.

It was a major step forward in my journey as a Full-Stack Developer, combining backend architecture, database design, frontend development, system administration, and real-world deployment into one complete project.
